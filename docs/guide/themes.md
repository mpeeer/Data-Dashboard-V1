## Preset Themes

| Theme | Shortcut | Appearance |
|---|---|---|
| Midnight | `Ctrl+1` | Dark, cool blue accents |
| Graphite | `Ctrl+2` | Restrained grayscale |
| Paper | `Ctrl+3` | Full light mode |
| Ember | `Ctrl+4` | Warm amber and orange |
| Auto | `Ctrl+0` | Follows your system preference |

## How to Switch

Click the theme button in the top bar to open the picker. Choose a preset, or select **Custom** to pick any accent color.

The theme picker supports keyboard navigation. Press `Tab` to focus, arrow keys to navigate options, and `Enter` to select.

## Custom Theme

Select **Custom** and use the color picker to choose any accent color. Lumen derives a complete light or dark surface palette from that single color — background tones, borders, text hierarchy, and chart colors are all generated automatically.

Custom accent preferences are saved to local storage.

## Transitions

All color changes animate with a smooth 0.3s cross-fade. Backgrounds, text, borders, and chart elements transition together — no jarring flashes.

## Chart Colors

Each theme includes a 6-color chart palette. All five chart types use these colors consistently, so switching themes gives the entire dashboard a cohesive new look.
